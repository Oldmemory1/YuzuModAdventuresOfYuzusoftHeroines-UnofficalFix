##### 时空脉冲光束线（`YUZU_VIBRANT_RAY_S/M/L_1`，反盾 · S/M/L 三槽） #####
#
# 2026-10-12 新建。设计稿见 markdowns/yuzu_spacetime_weapon_tiers.md §9.B：
#   · 反盾专精：对盾 ×4.0（+300%）、对装甲 ×0.5、对船体 ×0.5，**不穿透**（靠乘法硬拆）
#   · 伤害 / 耗电 / 追踪 = 时空线主炮同档同槽；命中比主炮高 0.05（太初 1.00 封顶）
#   · 射程远高于主炮（L Tier1 = 150，每档 +25）—— 交战第一轮就拆盾
#   · 蓄力 / 循环照抄主炮（3–12 / 35），四档不变
#   · 造价 = 主炮同档 ×1.25（四档随主炮的 ×1.75 / ×3.25 / ×5.5 走），维护费同比例 ×1.25
#     **不吃异星天然气**：§二「带 hull_damage 加成就吃气」那条规矩是为破体件定的，
#     本件是反盾件、hull_damage 是 0.5 的减伤，所以不套用
#   · 组件集 `YUZU_VIBRANT_RAY_1[_档位]`（S/M/L 三槽共用一套，与主炮 YUZU_ENERGY_TORPEDO_1 同规矩）
#   · 图标 `ship_part_yuzu_vibrant_ray_1[_档位].dds`；弹体/粒子 `yuzu_vibrant_ray_1[_档位]`
#   · 造价用字面量（不走 @变量，避免与 rebalance_adv_elite_tiers.py 的家族表互相牵扯）
#
# 命名：组件键 = 线名在前、槽位在后（`YUZU_VIBRANT_RAY_S_1`），组件集 = `YUZU_VIBRANT_RAY_1`
#      （`YUZU_VIBRANT_RAY_1` 这个键名来自 §9.B 的拍板，落在组件集上）。
#
# 注意：本文件**独立**存在，不塞进 yuzu_master.txt（那个文件是 make_yuzu_master.py 的生成物）。
