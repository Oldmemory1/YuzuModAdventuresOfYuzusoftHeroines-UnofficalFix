# 晶体镀层 —— 先进 / 精英 / 太初（时空线）与先进深渊（深渊线）
# 2026-10-13 新建。设计口径见 markdowns/yuzu_armor_spacetime.md §二：
#   · 船体值 = 同档装甲值（@yuzu_hull_*_<档>）；减伤每档 +2（原版水晶甲 +2 的那条线）
#   · 造价 ×2 / ×3 / ×4（相对 Tier1），只用稀有水晶；耗电 0、无维护费
#   · 升级链：…_1 → _1_ADVANCED → _1_ELITE → _1_MASTER；…_2 → _2_ADVANCED
#
# 为什么值/造价用 @变量 + 字面量、而且单独一个文件：
#   Tier1 在 yuzu_hulls.txt；先进 / 精英的造价变量归 rebalance_adv_elite_tiers.py 管、
#   太初档归 make_yuzu_master.py 管，把镀层塞进那两条流水线会互相牵连。
#   这里独立成文件：值用新的 @yuzu_hull_* 变量（不会撞生成器的清理正则），
#   造价直接写字面量（Tier1 也是这么写的）。
