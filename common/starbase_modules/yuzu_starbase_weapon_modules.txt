# 时空乱流系列恒星基地模块
#
# 结构参照 libra 的星界武器恒星基地模块：
#   workshop 3490581483 / common/starbase_modules/01_libra_starbase_weapon_modules.txt
#
# 恒星基地可选武器槽只有 M（BATTERY_STARBASE_SECTION 的两个 medium_turret），
# 因此这里挂载的是 S/M/L 时空乱流发射器组件集里的中型组件（YUZU_M_*）。
# 时空粉碎者（XL，extra_large）与湮灭巨炮（T，titanic）的组件尺寸超出恒星基地槽位，
# 无法用原版 section 挂载，故不在此文件中收录。
#
# 造价参照 yuzu_spacetime_weapon_tiers.md 的档位倍率：
# 先进 ×1.75、精英 ×3.25、太初 ×5.5，基准为原版电池模块的
# @defense_platform_section_cost（120 合金）与 25 稀有水晶。
#
# 本地化键：sm_starbase_yuzu_spacetime_launcher[_advanced|_elite|_master][_desc|_tt]
